# Frutiger Chat Download Site

A static, mobile-friendly APK download page. The APK is included as `Frutiger-Chat.apk` and all download buttons link to that file using a relative path.

## Publish with GitHub Pages

1. Create a **public** GitHub repository (for example `frutiger-chat-download`).
2. Upload the contents of this folder to the repository root. Keep `Frutiger-Chat.apk`, `index.html`, `styles.css`, `app.js`, and `assets/` together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your public page will be shown in Settings → Pages.

The repository must be public for the usual free GitHub Pages setup. Do not rename or move the APK unless you also update the download links in `index.html`.

## Before publishing

- Test the page and APK download on a phone.
- Only distribute an APK you own or have permission to share.
- Android may show a warning for apps installed outside Google Play. Users should install only if they trust the APK.
- This site does not verify the APK's safety, signing identity, or Android compatibility.
